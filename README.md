# David Halpern academic website — draft

This folder contains a self-contained GitHub Pages website with a concise research overview and a searchable publication list.

## Publish

1. Create a **public** repository named `dhalpern1.github.io` on GitHub.
2. Clone it using GitHub Desktop and copy **index.html** to the root of the cloned repository.
3. In GitHub Desktop, commit and push.
4. In GitHub, open **Settings → Pages** and choose **Deploy from a branch**, `main`, `/ (root)` if not already enabled.
5. Visit https://dhalpern1.github.io after Pages completes deployment.

## Review before publishing

- This is a curated first pass from the Google Scholar BibTeX pasted into ChatGPT: 47 journal records, two preprints, two chapters and a book. Conference abstracts, clear duplicate records and incomplete bibliographic records were omitted.
- Some bibliographic fields were abbreviated in the source and need verification (for example, page ranges and complete author names).
- The publication data are embedded in `index.html`; edit or regenerate that data when updating the bibliography.
- Publication links are Google Scholar title searches rather than fabricated DOI links.
- Review the concise research descriptions before publication. Add a verified personal Google Scholar profile URL and optional CV later.
